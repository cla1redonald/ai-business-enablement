# Quotation process note v2 (November 2026)

1. Request received by sales inbox; logged same day.
2. Desk checks rate card for the lane; if absent, requests rates from partners.
3. Quote built in the standard template. Target turnaround: 30 minutes from request
   for standard lanes.
4. Quote issued; follow-up at 48 hours.
5. On acceptance, sales forwards confirmation to operations for booking.

Note: rate cards are maintained per trade lane on Filestead under
Commercial/Rate Cards/. Surcharges updated overnight by the automated pull.
