# Using Verrin at Caldergate: interim note

Issued by the operations director's office, June 2027. To be reviewed "when the
picture settles".

1. Verrin may be used for drafting, summarising and internal analysis.
2. Do not paste customer commercial data, personal data, or carrier contract rates
   into Verrin.
3. Anything Verrin produces must be checked by someone competent to judge it before
   it is sent outside the company or relied on for a decision.
4. If in doubt, ask IT.

This note covers the Verrin assistant. Other tools' built-in AI features are not
covered. No named owner; queries route to the IT manager by default.
